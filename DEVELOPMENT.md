# DEVELOPMENT.md — GUÍA DE DESARROLLO

## 1. Instalación y Ejecución
```bash
npm install
npm run dev
```

El servidor de desarrollo correrá en el puerto 3000 (`http://localhost:3000`).

## 2. Comprobación y Calidad de Código
```bash
npm run lint
npm run build
```

## 3. Principios de Contribución
- Mantener estrictamente el principio de separación de Hechos, Análisis, Opiniones e Incertidumbres.
- Preservar la cero custodia de claves y secretos.
- Emplear siempre números con cifras tabulares (`font-mono-nums` / `tabular-nums`) en interfaces financieras.
